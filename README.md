# Сайт 02 (образец: Gravity Off, Behance)

Шаблон страницы под кодовое слово. Две вариации в одном дизайне:
- `gh/en/` английский, реклама Dias English, и `gh/en/lesson/` без рекламы;
- `gh/tr/` турецкий, реклама Alterna Timur, и `gh/tr/lesson/` без рекламы.
Корень `gh/index.html` ведёт на `/en/`, старый адрес `/lesson/` ведёт на `/tr/lesson/`.

## Как поменять
- **Тексты, ссылки, цены, порядок блоков** — в `content.en.json` и `content.tr.json`. Блок можно удалить, повторить или переставить в массиве `blocks` (польза) и `ad.blocks` (реклама). `*слово*` выделяется цветом, `[[фраза]]` помечается языком вариации.
- **Реклама** — раздел `ad` в каждом файле: автор с фото и его путь, платформа, экраны, цена, вопросы, подвал. Ссылка покупки в `ad.buy`.
- **Цвета и шрифты** — `theme` в файле вариации (попадают в CSS-переменные). Заголовки капсом выключаются строкой `headingCase: "none"`.
- **Картинки** — положить webp в `gh/media/` и указать имя в файле вариации. Свои картинки удобно собрать скриптом `tools/build-media.py` (он же обновляет `tools/media-sizes.json` с размерами).

## Пересобрать и проверить
```bash
node tools/build.mjs
cd gh && python3 -m http.server 8702 --bind 127.0.0.1
node qa/qa.mjs
```

## Типы блоков
`hero` первый экран · `about` абзац с подписью слева и цифры · `program` абзац, кнопка, картинка, два абзаца · `rows` цветные ряды · `statement` крупная фраза (с кнопкой или без) · `cards` карусель карточек (с большим скриншотом `big`) · `reviews` карусель отзывов-скриншотов · `price` цена и что входит · `faq` вопросы · `author` автор в волнистых фигурах.

## Публикация
Ветка `main` — исходники, ветка `gh-pages` — содержимое папки `gh/`:
```bash
git subtree push --prefix gh origin gh-pages
```
