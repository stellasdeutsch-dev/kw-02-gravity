# Сайт 02 (образец: Gravity Off, Behance)

Шаблон страницы под кодовое слово. Две версии: `gh/index.html` с рекламой и `gh/lesson/index.html` без неё.

## Как поменять
- **Тексты, ссылки, цены, порядок блоков** — всё в `content.js`. Блок можно удалить, повторить или переставить в массиве `blocks`. `*слово*` выделяется цветом.
- **Какую платформу рекламировать** — одна строка в начале `content.js`: `ad: "timur"` (Alterna Timur) или `ad: "dias"` (Dias English). Тексты и картинки каждой платформы лежат в `ads.timur` и `ads.dias`.
- **Цвета и шрифты** — `theme` в `content.js` (попадают в CSS-переменные). Заголовки капсом выключаются строкой `headingCase: "none"`.
- **Картинки** — положить webp в `gh/media/` и указать имя в `content.js`. Свои картинки удобно собрать скриптом `tools/build-media.py` (он же обновляет `tools/media-sizes.json` с размерами).

## Пересобрать и проверить
```bash
node tools/build.mjs
cd gh && python3 -m http.server 8702 --bind 127.0.0.1
node qa/qa.mjs
```

## Типы блоков
`hero` первый экран · `about` абзац с подписью слева и цифры · `program` абзац, кнопка, картинка, два абзаца · `rows` цветные ряды · `statement` крупная фраза (с кнопкой или без) · `cards` карусель карточек (с большим скриншотом `big`) · `reviews` карусель отзывов-скриншотов · `price` цена и что входит · `faq` вопросы · `author` автор в волнистых фигурах.

## Публикация
Ветка `main` — исходники, ветка `gh-pages` — содержимое папки `gh/`:
```bash
git subtree push --prefix gh origin gh-pages
```
